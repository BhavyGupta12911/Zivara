# 🌿 Zivara – Mental Wellness Flutter App

## 📱 Overview

**Zivara** is a mental wellness mobile application developed using **Flutter**.
It is designed to support users during stressful or emotional situations by providing calming tools, emergency support, and a personal safe space for meaningful memories.

This project was developed as a **major academic project** to promote emotional well-being through accessible digital support.

---

# ✨ Features

## 🚨 Crisis Mode

Provides immediate support during high-stress situations with:

* Quick-access calming tools
* Emergency support options
* Stress relief assistance

---

## 🧘 Breathing & Relaxation Tools

Guided breathing exercises and calming techniques to help users:

* Relax their mind
* Reduce anxiety
* Regain emotional control

---

## 🛟 Safe Haven (Memory Space)

A personal emotional safe space where users can:

* Store comforting photos
* Save meaningful videos
* Keep emotionally supportive memories

---

## 📩 SOS Emergency Messaging

Allows users to quickly send emergency alerts to trusted contacts during distress situations.

---

## 🎨 Calm UI Design

Designed with a peaceful and minimal interface:

* White background
* Soft purple-to-blue gradient theme
* User-friendly experience

# 🚀 Getting Started

```bash

```

## 2️⃣ Navigate to Project Folder

```bash

```

## 3️⃣ Install Dependencies

```bash
flutter pub get
```

## 4️⃣ Run the Application

```bash
flutter run
```
